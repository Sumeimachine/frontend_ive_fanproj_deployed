# Dive Into IVE PH

## Platform

Web. Existing React, Vite, Chakra UI and React Router frontend.

## Purpose and users

A non-commercial IVE fan-support community for Philippine DIVEs. Public visitors can explore member profiles, GrantSor's permitted photography, music metrics, fan events, community pages and quiz leaderboards. Signed-in fans can access the daily quiz, card game and fan points. Existing administrator tools remain role-gated.
