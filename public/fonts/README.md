# Self-hosted fonts

Oswald and Manrope Latin variable font files, normal style, from the Fontsource variable packages version 5.3.0. Downloaded 2026-09-17. Their SIL Open Font License texts are retained beside the files.

- https://registry.npmjs.org/@fontsource-variable/oswald/-/oswald-5.3.0.tgz
- https://registry.npmjs.org/@fontsource-variable/manrope/-/manrope-5.3.0.tgz

These are served locally; the website does not make third-party font requests.
